Rigframe · 使用说明

一个跑在浏览器里的手书 / 对口型动画工具。你负责画，它负责让画动起来、卡上点、导出成视频。

它不是：不是绘图软件（画还是在你自己的软件里画），不是专业动画软件（没有骨骼蒙皮、没有曲线编辑器级别的深度）。

它是：把「分层 PNG + 一首 BGM」变成「一条卡点手书视频」的最短路径。

一、三分钟跑通第一条片子

第 1 步：打开

双击 prototype/index.html，用 Chrome 或 Edge 打开（原因见文末「浏览器要求」）。

第一次打开会看到中间有一个「载入示例角色」按钮。先点它，用自带的示例角色熟悉操作，比直接导入自己的图快得多。

第 2 步：准备并导入分层图

在自己的绘图软件里把角色拆成部件，每个部件导出成一张 PNG，所有图层用同一个画布尺寸导出（不要各自裁剪），这样导进来能自动对齐。

文件名按这个格式：

部位__变体.png

例如：

head__normal.png
head__happy.png
arm_l.png
arm_r.png
body.png

把这几张图一起拖进窗口任意位置即可。

第 3 步：摆位置

在画布上拖拽部件调整位置；选中后会出现一个白色变换框，拖四个角的圆点缩放，拖右下角的圆钮旋转。滚轮是缩放视图（推拉镜头），中键拖拽平移画布。

⚠️ 这一步会产生关键帧（见「自动记录」）。如果你只是想摆初始姿态，先点底部工具栏的「● 自动记录」把它关掉，摆完再打开。

第 4 步：卡点

导入音乐（顶栏「导入音乐」，或直接把音频文件拖进窗口）。

播放，跟着节奏按 T，或者点底部「＋ 卡点」，卡点标记会落在时间轴标尺上。

第 5 步：放动作

右侧「动作」标签里有一堆现成动作（点头、挥手、跳一下、震惊……）。把播放头放到想开始的位置，点一下卡片，时间轴上就出现一个动作片段。

片段可以拖动位置、拖右边缘拉伸时长。

第 6 步：导出

顶栏「导出视频」→ 选帧率 → 开始导出。得到一个 .webm 文件。

二、准备素材的规范

图层要求

项目要求
格式PNG（带透明通道）
画布尺寸所有图层必须一致，且部件在画布上的相对位置保持原样
拆分粒度至少要分开：身体、头、左右手臂
分辨率建议 1000×1000 以上

为什么必须同尺寸导出：软件靠透明像素的包围盒自动算轴心和对齐，如果每个图层各自裁剪，导进来会散架（可以手动拖回去，但很麻烦）。

命名与自动识别

软件按文件名里的关键词判断这是哪个部位：

文件名包含识别为挂到谁下面
head 头 face 脸 面 hair 发 eye 眼 mouth 嘴 brow 眉头部身体
arm 手 臂 + _l left 左左臂身体
arm 手 臂（不含左）右臂身体
leg 腿 脚 foot腿身体
其他身体无（根节点）

变体用双下划线分隔：head__normal.png 和 head__happy.png 会被认成同一个部位的两张贴图，在属性面板里一键切换。

左侧：图层面板

面板顶部有两个分页，同一份数据，两种看法：

分页用途
图层平铺列表，按遮挡顺序从上到下排。只管「谁在前面、谁在后面」，不显示缩进
父子级树状列表，父级显示为文件夹（带折叠箭头），子图层缩进显示。只管「谁跟着谁动」

两个分页都能拖动行改顺序；按住 Alt 拖到某一行上 = 把图层放进它下面（成为子图层），在「父子级」里看最直观。

  • 每层有缩略图、名称、显示/隐藏、锁定
  • 平铺列表里，子图层名字前面有个小 ⤷，鼠标悬停能看到父级是谁
  • 双击名称可改名

点透明处会自动选到下面那层：画布上的命中判定是逐像素的（读贴图的 alpha），点在某个图层的透明区域时，会往下找第一个真正不透明的地方。所以头发中间的空隙、手臂之间的缝，点下去选中的是身体，不是头发。如果整片区域都是透明的，仍然保留最上面那一层的选中，不会突然什么都没有。

底部两个按钮：＋ 贴图（给当前图层追加贴图变体）、删除。

每张贴图缩略图右上角有个小 ×，可以删掉这一张。删到只剩一张时不能再删（图层至少要有一张贴图）。删除后关键帧里记录的贴图序号会自动夹到有效范围，不会出现空图。

中间：画布

  • 拖拽：移动部件
  • 拖四角白点：缩放（缩放是围绕轴心进行的）
  • 拖右下角圆钮：旋转，靠近 15° 的整数倍会自动吸附
  • 左上 ×：删除这个图层（可撤销）
  • 左下 +1：复制一份图层
  • 滚轮：缩放视图（推拉镜头，像 Blender 那样）
  • 中键拖拽：平移画布
  • 右键：视图菜单（适应窗口 / 实际大小 / 放大缩小）
  • 点空白处取消选中
  • 白框是当前选中的部件，框中间的绿点是它的轴心，旋转和缩放都绕这个点

右侧：四个标签页

标签作用
属性当前图层的名称、父级、贴图、变换、轴心、关键帧
曲线选中关键帧后调缓动曲线
动作动作库 + 我的组件
场景画布尺寸、背景、音频

改画布尺寸时，内容会按比例跟着缩放，规则是：

  • 只改了一边（比如只把宽从 1000 改成 2000）→ 按改的那一边缩放，内容跟着变大/变小
  • 两边都改了（比如切到 1080×1920 预设）→ 取较小的比例，保证内容装得下、不被裁切，多余空间居中留白

不需要这个行为时，把「改尺寸时按比例缩放内容」关掉即可。

底部：时间轴

  • 左侧是图层名，右侧是内容
  • 方块 = 动作片段，菱形 = 关键帧
  • 橙色小三角 = 卡点标记
  • 白线 = 播放头

工具栏从左到右：播放、时间码、BPM、拍号、吸附、自动记录开关、手动加关键帧、加卡点、加贴图事件、存为组件、插入动作、缩放。

工具栏下面还有一条 MIDI 栏和一块可折叠的钢琴窗（见「MIDI 口型」一章）。钢琴窗收起时只占一行按钮；展开后时间轴会自动让出高度，两者共用同一套时间刻度，播放头对齐。

四、几个必须理解的概念

1. 图层树：父级动，子级跟着动

每个部件都有「父级」。默认身体是根节点，头、手臂挂在身体下面。

这意味着：身体播放「跳一下」时，头也会跟着跳（因为它挂在身体下面）。这是正确的、符合直觉的行为。

如果不想让某个部件跟着父级动，在属性面板把它的「父级」设为「（无父级）」。

2. 轴心：旋转和缩放的中心

每个部件都有一个轴心（画布上的绿点）。旋转、缩放都围绕它进行。

默认位置：图形自身包围盒的中心。

为什么重要：手臂的轴心应该在肩膀，不是在手臂中间。轴心不对，转起来就像风车。

怎么改：

  • 属性面板「轴心」区，直接填 X / Y 数值
  • 或者点「画布上点选」，然后在画布上拖动橙色十字准星
  • 改错了点「回到中心」

关键特性：轴心是按比例存在所有贴图上的。同一部位换成不同尺寸的贴图，轴心会等比跟随，不会错位。

改轴心不会带动子级。 子级的坐标是相对父级轴心的，按原理改轴心会让整条子级链漂移。这里做了补偿：改完之后子级在画面上原地不动，只是父级的旋转中心变了。

3. 关键帧 vs 动作片段（最容易混淆的地方）

这个工具有两套并行的动画方式：

关键帧动作片段
长什么样时间轴上的小菱形时间轴上的彩色方块
怎么产生改属性时自动记录从动作库拖/点出来
怎么编辑逐个调属性、调曲线拖动位置、拉伸时长
适合精细的手工动画快速套用常见动作

重要规则：动作片段会覆盖同一时间段内的关键帧。

当播放头落在某个片段范围内时，属性面板会出现橙色提示：

当前时间在动作片段「点头」内，属性修改会被片段覆盖。

这时候你改属性、调曲线都不会生效——因为片段说了算。

选中关键帧后改属性，改的就是这一帧。 点时间轴上的菱形，播放头会跳到这一帧，之后你在属性面板里改旋转、位置、缩放，都是直接改这个关键帧，不会在旁边多插一帧。拖动菱形时播放头也会跟着走，所见即所改。

（拖播放头、按方向键会把关键帧选中状态清掉，避免「改了 A 帧却以为在改当前时刻」。）

播放时属性面板是实时刷新的。 播放头走到哪，面板里的 X / Y / 旋转 / 缩放 / 透明就显示那一刻的数值，方便你观察动作曲线是否正常。

想混用怎么办：先把片段「分解为关键帧」（右键片段 → 分解为关键帧），它就变成普通关键帧，之后所有编辑都生效。

4. 组件：把一段关键帧存成可复用的动作

自己调了一段满意的动画？可以存成组件，以后反复用。

打包：选中关键帧（或直接选中图层用它的全部关键帧）→ 底部「＋ 存为组件」→ 命名。

打包后会发生什么：原来的关键帧会被替换成一个片段，画面完全不变。这样你可以把它当成一个整体来拖动、拉伸。

拆开：右键这个片段 → 分解为关键帧。

跨图层复用：组件存的是相对量（相对于起始姿态的偏移），所以头部的动作可以套到身体上，不会飞出去。

保存位置：浏览器的 localStorage。刷新不丢，但换电脑/换浏览器就没了。

5. 镜像

属性面板「变换」里有 ⇋ 水平镜像 和 ⇅ 垂直镜像 两个按钮（桌面快捷键 H / V）。

镜像围绕轴心进行，图形原地翻转，位置不动。

父子关系是继承的，不是传播的：

  • 镜像父级（比如 body）→ 所有子级（head / arm）跟着翻转
  • 子级自己的 flipX 仍是关闭状态，只是被父级矩阵带着翻
  • 所以子级再点一次「水平镜像」，会抵消父级的翻转，让这一层单独恢复正常朝向

这就是「单独镜像」的用法：父级整体镜像后，某个部件想保持原样，选中它再镜像一次即可。

镜像可以打进关键帧。 点镜像按钮时，如果这个图层已经有动画（有关键帧），会强制在播放头落一帧——否则下一次求值就会把镜像回滚掉。翻转状态保持到下一个关键帧，然后瞬间切换（离散属性，不做渐变）。所以「人物转身」「左右张望」这类动作用两个关键帧就能完成。

镜像选中的关键帧和片段（把整段动画翻过来）：

  • 在时间轴上选中关键帧（Shift 点选或框选）和/或动作片段
  • 右键 → 「镜像选中（水平 / 垂直）」，或按 Shift + H / Shift + V
  • 关键帧和片段会被一起翻转，不影响图层当前姿态

这适合「一段挥手动画，想直接改成反方向」：框选整段 → Shift + H，不用逐个调。

片段有自己的镜像状态。 动作片段是独立的一段动画，所以它记着自己的翻转：

  • 选中片段按 Shift + H → 这段动画整体翻转
  • 播放头落在片段里时点「水平镜像」→ 改的是这个片段，不是整个图层
  • 播放头在片段外时点「水平镜像」→ 改的是图层关键帧

镜像和缩放是分开的属性。把 缩放X 拉到负数不会触发镜像（会被限制在 10% 以上），要翻转请用镜像按钮。

6. 发丝摆动 / 形变

给挂在父级下的图层（头发、呆毛、裙摆、尾巴）加滞后摆动：父级一动，它就慢半拍跟上来，停住后再慢慢回位。

属性面板「发丝摆动」区：

参数作用
阻尼越大回位越快、越"硬"；越小越软、晃得久
跟随对父级运动的敏感度，越大甩得越开
最大角摆动幅度上限，防止穿模
随风开关。关掉时只跟随父级运动，不做自发的风摆；打开后按下面的角度和频率额外摆动
网格变形开关。关 = 整层绕轴心摆动；开 = 沿发丝方向弯曲（见下）

两种模式：

  • 整体摆动（网格变形关）：整个图层绕自己的轴心转一个角度。适合呆毛、尾巴、小挂件。
  • 网格形变（网格变形开）：把图层沿纵向切成 N 段，每段单独旋转，形成连续的弯曲。适合长发、飘带。段数 3~500，默认 32。

「最大角」是整条发丝的总弯曲角，不是每段的角度。段数只决定平滑度：8 段能看到折线台阶，40 段基本看不出来，200 段完全平滑。实测 120 段单帧绘制 0.63ms，200 段约 1ms，性能不是瓶颈；但段数越高，关键帧里存的角度数组越长，工程文件会变大。

点「生成摆动关键帧」/「生成形变关键帧」→ 从 0 帧烘焙到片子结束，每 1/24 秒一帧，写进这个图层的关键帧。

网格形变的原理：图层的包围盒纵向切成 N 段，每段绕上一段的末端旋转，角度存在关键帧的 bend 数组里（每帧 N 个数）。

三个让它看起来顺的细节：

  1. 总角按权重分配：bend[k] = 总角 × 权重 / 权重和，所以改段数不会改变弯曲程度，只改变平滑度。
  2. 每段用「上一段 + 本段」的平均角绘制，并居中在段中点：接缝两侧各差一半，台阶减半。
  3. 相邻段多画 60%（最多 3px）：盖住弯折内侧的楔形缝。

跟随的驱动信号有两个：父级的旋转（发丝落后）和父级的水平位移（发丝甩向反侧，位移除以发丝长度换算成角度）。所以就算父级只是平移、完全不转，发丝也会甩起来。

波是沿着发丝往下传的：第 k 段取的是「根部响应」延迟一点点的值（根到梢共延迟 0.28 秒），所以是梢部最后停下，不是整根一起僵直地动。

实测效果（父级 1 拍内转头 0°→40°）：

0.00 拍  父=0.0°    发丝局部=0.0°
0.50 拍  父=20.0°   发丝局部=-13.7°   ← 落后于父级
1.00 拍  父=40.0°   发丝局部=-15.9°   ← 甩到最大
1.50 拍  父=40.0°   发丝局部=-6.4°    ← 回弹
2.00 拍  父=40.0°   发丝局部=-2.6°    ← 归位

多段链条：把头发拆成「发根 → 发中 → 发梢」三层父子关系，选中发根点一次生成，整条链会依次滞后（子级的父级已经带了摆动，所以是级联的）。

它是烘焙成关键帧，不是实时物理。好处是能预览、能手动改、导出和预览完全一致；代价是改参数后要重新点一次生成。已经有关键帧动画的图层会在原动画基础上叠加摆动。

7. 自动记录（全局开关）

底部工具栏的「● 自动记录」，对所有图层生效，不是单个图层的设置。

  • 开（默认，橙色高亮）：改任何属性都会在播放头位置落一个关键帧
  • 关（灰色）：改属性只改当前姿态，不落关键帧

旁边的「＋ 关键帧」是手动打帧：给当前选中的图层在播放头位置插一个关键帧，不受自动记录开关影响。适合「我想精确控制在哪一拍落帧」的场景。

什么时候该关自动记录：第一次摆位置、对齐部件的时候。否则你会在一堆位置上留下关键帧。

8. MIDI 口型（钢琴窗）

这是给「对口型」准备的一整套东西：把 MIDI 音符变成贴图切换。

为什么用 MIDI 而不是直接听音频：音频里没有「哪个音、什么时候开始、什么时候结束」这种结构化信息，MIDI 有。很多虚拟歌手、编曲软件都能导出 MIDI。

三步走

  1. 导入 MIDI：点 MIDI 栏的「导入 MIDI」，或者把 .mid 文件拖进窗口。钢琴窗会自动展开。
  2. 选口型图层 + 自动映射：在「口型图层」里选你的嘴（这个图层要先有几张不同口型的贴图，用 ＋ 贴图 加）。点「自动映射」，它会把当前通道里的音高从低到高依次分配给你的贴图。
  3. 生成口型：点「生成口型」，音符就变成这个图层的贴图关键帧，播放时嘴会跟着音高开合。

生成的是普通关键帧（带一个「口型」标记），可以照常拖动、删除、调曲线，也可以被撤销。想重来点「清除」即可。

钢琴窗怎么看

  • 左边是音高行，从上到下由高到低，行名就是音名（C4、D4…）
  • 右边是音符方块，横轴和时间轴完全对齐
  • 有口型图层时，音高行右侧会显示这个音高映射到哪张贴图，颜色和音符一致
  • 点音高行左侧的名字 = 换一张贴图（循环切换）。改完如果已经生成过口型，会自动重新生成
  • 在音符区点击/拖拽 = 定位播放头（和时间轴标尺一样）
  • 滚轮 = 上下滚动音高；Ctrl + 滚轮 = 缩放时间刻度

通道很重要

一个 MIDI 文件里往往同时有旋律、和声、鼓。鼓轨也会被当成音符，直接生成会让嘴乱动。所以 MIDI 栏有一个「通道」筛选：选成旋律/人声那个通道，钢琴窗和口型生成都只认这个通道的音符。

默认行为：文件只有一个通道时自动选中它；有多个通道时默认「全部」，这时需要你自己挑一下。

「静音贴图」是什么

音符和音符之间的空隙（换气、休止）用哪张贴图——一般就是闭嘴那张。默认是第 1 张。

速度对不上怎么办

工具是按拍工作的：MIDI 的 ticks 直接除以 PPQ 当作拍，不重建速度曲线。

  • 工程 BPM 和 MIDI 原速一致时，音符落在完全正确的小节位置上
  • 不一致时，音符仍然落在正确的音乐网格上（小节、拍子对得上），但和音频的绝对时间会偏
  • MIDI 栏会显示文件里的原速（比如 120 BPM），照着它把工程的 BPM 调成一样即可

六、导出

顶栏「导出视频」打开导出对话框。

参数说明
帧率24 / 30 / 60 fps。手书一般 30 够用，卡点很密的可以上 60
尺寸100% / 75% / 50%，右侧会显示实际输出像素
范围起止秒数。默认从 0 到内容结束
时长只读，显示范围长度

输出格式：.webm（VP9 视频 + Opus 音频）

导出是离线逐帧渲染的，比实时快。30 秒的片子通常几秒到几十秒，取决于分辨率和帧率。

透明背景会变成黑色——WebM 这个格式在当前封装下不带透明通道。

保存 / 打开工程

按钮作用
导出工程把整个工程存成 .json，贴图以 base64 内嵌，文件是自包含的
导入工程选一个之前导出的 .json，整份工程原样恢复

工程文件里包含：画布尺寸、背景、BPM / 拍号、卡点、所有图层的贴图与层级、变换、关键帧、动作片段（含镜像状态）。

因为贴图内嵌，文件会比较大（几张 1000×1000 的 PNG 大约几 MB），但好处是可以直接发给别人，不用附带图片文件夹。

导入会替换当前工程，并且清空撤销历史。导入前记得先导出存一份。

音频偏移

场景标签 → 音频区有「偏移」滑块（±3 秒）。

  • 正数：音乐延后
  • 负数：音乐提前

实用技巧：把播放头放在画面开始动的那一拍，点「对齐到播放头」，音乐就会从那里起。比手动拖滑块试快得多。

七、常见问题

Q：导入后部件全叠在一起 / 位置乱了

导出图层时没有用同一个画布尺寸。回去重新按统一尺寸导出。临时救急：手动拖到正确位置，或者用「自动记录：关」状态下摆好。

Q：旋转的时候部件飞出去了

轴心位置不对。点属性面板「画布上点选」，把十字准星拖到该转的地方（手臂拖到肩膀，头拖到脖子）。

Q：改了属性画面没反应

大概率是播放头落在某个动作片段范围内，片段覆盖了你的修改。看属性面板有没有橙色提示。要么把播放头移出去，要么把片段分解为关键帧。

Q：导出的视频没声音

检查场景标签的音频区是否显示「已加载」。如果是「未加载」，说明音频没有真正导入（可能格式浏览器不支持，换 mp3 试试）。

Q：导出很慢 / 卡住

降低分辨率（选 50%）或帧率（24fps）再试。4K 分辨率下 VP9 软编码会很慢。

Q：刷新页面后我的组件没了

组件存在 localStorage 里，正常情况下刷新会保留。如果清理过浏览器数据或用无痕模式，会丢失。

Q：能导入 mp4 音乐吗

不能直接导入视频文件。用其他工具把音轨提取成 mp3/wav 再导入。

Q：时间轴上的数字是什么

大数字是小节号，小数字是拍号。4/4 拍时，一个小节 = 4 拍。放大时间轴（Ctrl+滚轮）才能看到拍号。

Q：导入 MIDI 后嘴不动 / 乱动

三件事按顺序查：①「口型图层」选的是不是嘴那个图层；②「通道」选的是不是旋律/人声那个通道（选「全部」会把鼓也当音符，嘴就会抽）；③点了「生成口型」没有——只导入 MIDI 是不会自动生成关键帧的。

Q：点了「生成口型」提示有动作片段

那个图层上有动作片段，片段会覆盖关键帧。先在时间轴上把片段「分解为关键帧」，再生成口型。

Q：MIDI 音高太多，一个音高一个贴图不够分

正常。「自动映射」是按音高从低到高均分到现有贴图的，音高多于贴图时会合并。想改某个音高：在钢琴窗左侧点它的音高名，循环切换贴图。

八、浏览器要求

浏览器支持情况
Chrome / Edge 94+✅ 完整支持（推荐）
Safari 16.4+⚠️ 大部分功能可用，导出可能受限
Firefox❌ 导出不可用（缺少 WebCodecs 视频编码器）

导出功能依赖 WebCodecs，这是较新的浏览器 API。如果打开后导出报错「浏览器不支持 WebCodecs 视频编码」，换 Chrome 或 Edge。

九、已知限制

诚实地列一下现在还做不到的事：

  1. 只能导出 WebM，没有 MP4。B站、YouTube 直接支持，但微信、部分手机相册不认。
  2. 没有参考视频叠底。想对着原片画符对位，现在做不到。
  3. 组件不能跨设备/跨项目分享。只存在本机浏览器里。
  4. MIDI 不重建速度曲线：只按拍对齐（见「速度对不上怎么办」）。
  5. 一次只能给一个图层做口型。多人对话要先分别生成。
  6. 口型是按音高查表，不是按音量/音素。想要更细的嘴型得自己改关键帧。
  7. 时间轴没有吸附到其他关键帧，只有吸附到拍线。
  8. 没有多轨音频，只能有一条背景音乐。

十、一条建议的工作流

给第一次做手书的人：

  1. 先画完整张图，再拆分。拆的时候想象每个部件要怎么动。
  2. 拆得比你以为的细一点。头发、眼睛、嘴巴单独拆出来，能做的表情变化多很多。
  3. 先卡点，再画。把 BGM 导进来，跟着节奏打满卡点，再决定每个卡点画什么。
  4. 先用动作库搭骨架，不满意的地方再分解成关键帧手调。
  5. 中途多导出几次看看效果，别等做完才发现节奏不对。
